# Lakers Ticket Demand: The LeBron Effect

**Research question:** How much of the Lakers' ticket demand and pricing power came from LeBron James, compared with the Lakers brand, Luka Dončić, the Los Angeles market, and team success?

**Approach:** A hedonic regression of secondary-market ticket prices on star availability (LeBron and Luka playing or not), opponent quality, game timing, and team performance, plus a comparison against peer teams.

**Data sources (planned):** SeatGeek API (daily price snapshots), Basketball-Reference, and the nba_api package.

**Status:** Work in progress. Data collection began in October 2026, and post-LeBron results will update as the 2026-27 season continues.
